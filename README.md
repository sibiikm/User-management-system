User Management System

This is a User Management System-based authentication system that includes email and password validation, login functionality, and toast notifications.

Features

Email and password-based login

Form validation with real-time feedback

Error handling with toast notifications

Redirects to the dashboard after successful login

Installation

1. Clone the Repository

[git clone https://github.com/your-username/react-login-app.git](https://github.com/sibiikm/User-management-system.git)
cd user-management-system

2. Install Dependencies

npm install

3. Start the Development Server

npm start

This will start the application at http://localhost:3000/.
